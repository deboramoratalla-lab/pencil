# Pencil multi-format canvas — local prototype

The prototype is compiled into a standalone HTML file. It does not need npm,
a development server, or an internet connection.

Open `pencil-canvas-v8.html` in Safari, Chrome, or Firefox.

The editable source now lives beside the prototype as `pencil-canvas-v8.jsx`.
To rebuild the standalone HTML after changing it:

```bash
node build.mjs
```
